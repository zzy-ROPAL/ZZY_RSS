## 1. 目标(一句话)

1-D 焊缝任务,机器人的**起始位姿**所在的页**到不了终点**;
它经过一个**奇异点**换到另一页,在那一页**到得了终点**。

## 6. 最重要的一个坑:**弱命题 vs 强命题**

我自己在这上面错了一整轮,所以单独写出来。

```
强命题(错的那个):页 P 上【所有】碰到 y=0 的区域都到不了终点
弱命题(对的那个):【起始位姿所在的那一个区域】到不了终点     ← 不变量 16c
```

前面所有搜索都在查强命题,于是 640 个有门的摆放里一个都没过。
换成弱命题 + 障碍,res 61 上立刻出 **145 个**候选。
**`run_proof` 必须传 `seeds=[(page, region)]`**,否则它默认播种
"八页上所有碰到 y=0 的区域",证的就是强命题 —— §29(c) 实测这会把
γ 从 1.3 顶到 **334**,墙根本建不起来。

## 8. 能直接用的工具

| 工具 | 用途 |
|---|---|
| `src/zzy_rss/fasteval.py` | **场景搜索加速器**。每个摆放预计算一次(0.37 s @ res 41),之后每个障碍 **12.9 ms**(原来 ~400 ms)。另有 `asymmetry_band()` 与 `band_thickness()`。`tests/test_ik.py::test_fasteval_matches_page_build` 断言它与真实页图逐格一致 |
| `pagemap.build_all_pages_shared` | 八页的价钱按一页算(4.5×,逐格精确) |
| `doors.find_interior_doors_analytic(cfg, arm, weld, pm, 2)` | **解析** q6 门(二次方程,至多两根),不用扫网格 |
| `doors.door_fiber_validity` | 门是否开(纤维扫描),返回 `valid_fraction` 与 `blockers` |
| `pagemap.mirror_q(q, 2)` | `s₆` 镜像,用来查伙伴页代表元是否在限位内 |
| `flood.run_proof(..., seeds=[...])` | 真正的判定 |
| `scripts/run_three.py` | EXP 3 那一段就是跨页实验的模板(图 + 过门图 + 视频) |
| `scripts/run_e4.py` | 旧的 E4 扫描;**它查的是强命题**,要改成弱命题才有用 |

`band_thickness()` 的用法(便宜的预筛):一个摆放若其可分离的带格
**不构成一条连通的串**,就支持不了"障碍割 P 而不割 Q"。
实测三个摆放:可分离格 **2/328、0/330、4/556**,且全是孤立格、全坐在焊缝端点
(§35)。本场景能成立不是靠分离带,而是靠**弱命题**让 P 的割口可以在别处。
