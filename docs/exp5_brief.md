## 1. 目标(一句话)

把门从**点**换成**线**:用 `q4` **折叠门**(手臂完全伸直、肘部翻转)
代替 `q2`/`q6` 点门,跑完一个 `Y⁺` 的跨页不可行性证明。

---

## 2. 为什么它值得做(三条,都已实测)

| | 点门(EXP 1–4) | **线门(EXP 5)** |
|---|---|---|
| 在页 `(y,θ)` 里 | 一个**点** | 一条**线**(该 y 的整条 θ) |
| 在构型空间 `Q` 里 | 一条**线**(自运动纤维) | 一个**点** |
| 门的认证 | 采样纤维 —— 纤维是 `Q` 里的**零测集**,采样只是证据(待办 5) | **精确**:整条 θ 线是**一个**物理构型 ⇒ 一次碰撞 + 两次限位 |
| 物理可穿越余量 | q2 门 **−1.15°**(永远不行,§30);q6 门 +14.46°(EXP 4) | **+21.4°**,而且是经典的**肘部翻转** |
| 单页证明是否可能 | 可能(墙能把点门围在里面,EXP 2 就是) | **不可能** ⇒ 证明**被迫**换页 |

第三条是最有价值的:**EXP 5 让"必须换页"成为结构性结论,而不是"门恰好开着"。**
EXP 3 想演示这件事,但它依赖门的开关 —— 换个摆放 16 道门全关(§26)。

实测数字(x0.60 z0.40 倾角 15°,折叠点 `y* = 0.15850499`):

```
y*+1e-6 处沿整条 θ 扫一圈,连杆最大位移:
   shoulder 0.000e+00 m   elbow 4.299e-04 m   wrist 1.010e-13 m   tool 1.011e-13 m
离折叠点 0.05 处同样扫一圈:  elbow 9.251e-02 m
s4=+ : IK 361/361,在限位 355/361,最佳余量 0.374 rad = 21.4°
s4=- : IK 361/361,在限位 356/361,最佳余量 0.374 rad = 21.4°
q4 = ±0.076°(两页在折叠点真的合并了)
```

肘部从 92.5 mm 的摆动缩成 **0.43 mm** ⇒ 整条线是同一个姿态。

## 3. 必须先写的代码(没有它场景不存在)

**硬约束(不变量 22)**:直焊缝 + 固定工具姿态 ⇒ `W(y)` 对 y **仿射**
⇒ `|W(y)−S|` **凸** ⇒ 可达 y 集是**一个区间** ⇒ 折叠只能落在区间**端点**,
也就是任务离开工作空间的地方,**不可能落在任务内部**。
扫 2280 个直焊缝摆放实测:**非凸 0 个**。现有三个案例
`|W−S| ∈ [0.4121, 0.4873]`,离 `reach_max = 0.6510` 很远,**一个 q4 门都没有**。

所以必须打破 `W(y)` 的仿射性:

| 文件 | 改什么 |
|---|---|
| `src/zzy_rss/weld.py` | `WeldLine` 从直线推广到**参数曲线**:`position(y)` 任意曲线,`pose(y)` 返回 `(p(y), R(y))`。`pose()` / `wrist_center()` 是所有下游代码**唯一**的入口,所以这是一处**受限**改动 |
| `src/zzy_rss/params.py` | `WeldParams` 加曲线类型(直线 / 圆弧)与姿态插值开关(工作约定:参数不硬编码) |
| `src/zzy_rss/doors.py` | `find_fold_doors` 与 `find_interior_doors_analytic` 现在解 y 的**二次方程**(靠仿射性);曲线缝下要换成**数值求根**(对 `\|W(y)−S\| − reach_max` 以及 q2/q6 条件各做一次 Brent/二分) |
| `src/zzy_rss/doors.py` | 折叠门的认证改成"查**一个**构型"的精确路径,不再走 `door_fiber_validity`(这同时关掉**待办 5**) |
| `tests/test_ik.py` | 曲线缝下 `pose()` 的 FK 往返;折叠点 `q4=0` 与"整条 θ 线一个姿态"的断言 |
| **不用改** | `wall.py`、`scene.py`、`flood.py` —— 墙、碰撞、泛洪都不关心焊缝是直的还是弯的,`flood` 已经把圆盘当通用对象处理 |

`find_fold_doors` **已经按线门实现了**(在折叠的 y 上沿整条 θ 铺圆盘),
所以这一侧不用动,只要把"折叠点在哪"从二次方程换成数值求根。

### 已经验过的可用曲线

圆弧缝,圆心 `(0.50, 0.36)`、半径 `R = 0.18`:
`|W−S| ∈ [0.3356, 0.6810]`,二阶差分最小 **−6.6e-6 < 0(非凸)**,

(圆弧缝在工业上也最常见:管-板环缝、法兰环缝。)

| | 伙伴页(`s₄` 翻转)里 | `run_proof` | 难度 |

| **EXP 5b** | 到达区域**到不了**终点 | `proven=True`,**两页两面墙** + 线门 | **先做这个** |

## 6. 一个必须说清楚的边界

折叠线**不会**把页切断。`q4 = s₄·arccos(u)`,折叠处 `u=1` 故 `q4=0`,
两侧 `u<1` 所以在 `s₄=+` 页上 `q4>0` **两侧都有定义** ⇒ 同一页内**可以**跨过 `y*`。
而且整条 θ 线是同一个构型,**跨线时 θ 可以任意跳** ⇒ 折叠线让页**更连通**。
Σ 从不判无效(不变量 1)。

折叠线给出的性质是关于**墙**的:`find_fold_doors` 在 `y*` 铺满整条 θ 的圆盘,
围住起始区域的闭合墙必须从 `y > y_max` 绕回虚拟边界带(`y < 0`),
于是**必然两次穿过 `y = y*`**,而 Σ 守卫(`segment_hits_disc`)会拒绝那些面。

**两点**:(a) "整条 θ 都铺圆盘"是保守建模(不变量 2),只会让证明多做功;
(b) 若折叠线真的整条都过不去,Stage 5 会认证关闭、`live_discs` 卸掉圆盘,
墙又可以穿过 `y*`,单页证明重新成立 —— 结论仍然正确(机器人到不了 `y > y*`)。
两种情形都可靠,区别只在证书长什么样。**所以条件 C 的精确认证是关键的。**

## 7. 成功判据(机器可查)

1. 存在折叠点 `0 < y* < 1`,`y*` 两侧都可达,且 `q4` 在 `y*` 处为 0(到 1e-6)。
2. 折叠线上**存在**一个 θ,其两个 `s₄` 代表元都在限位内 ⇒ 门开(精确,不是采样)。
3. 不带障碍时,墙**无法**在起始页闭合(Σ 守卫因穿过折叠圆盘而拒面)——
   这条要显式验证,它是 EXP 5 的核心论点。
4. 5b:`run_proof(seeds=[(P, k_start)])` 返回 `proven=True`,
   证书含**两页两面墙**(都闭合、面覆盖 100%)+ 一道**折叠门**。
5. 以上在 **res 61 与 res 81** 上都成立(不变量 23)。
6. 一段连续运动:起点 → 折叠点(手臂伸直)→ 肘部翻转 → 在伙伴页继续,
   工具全程在焊缝上。
