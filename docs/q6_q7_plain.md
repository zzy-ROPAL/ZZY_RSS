# 问题 7 先讲:八页为什么长得一样 —— 因为它们**就是**同一条手臂

这一条是两个问题里更根本的,先讲它,Q6 会变好懂。

## 一个比方:同一个时刻的两种写法

「晚上 11 点」和「23:00」是**同一个时刻**,只是两种写法。
你不会说"这是两个不同的时刻",也不会说"这两个时刻长得很像" ——
它们本来就是一个。

**八页就是这个关系。** 对一个固定的 `(y, θ)`:

- `y` 把焊枪钉在焊缝上的某一点
- `θ` 把肘部钉在自运动圆上的某一点

这两个数一定下来,**肩、肘、腕、工具在空间里的位置就全定了**。
八个符号分支 `(s₂, s₄, s₆)` 只是把**这一个姿态**用八套关节数字写出来。
手臂在空间里一动不动,动的只有纸面上的数字。

(这不是比喻,是断言到 3e-16 的测试:
`tests/test_ik.py::test_branch_geometry_identical`。)

## 由此直接推出三件事

### 第一件:碰撞不可能因页而异

手臂在同一个地方,障碍物当然碰到的是同一条手臂。
实测(EXP 3 场景,61×61 逐格重算碰撞、不看限位):

```
八页之间的差异格:  0 / 3721   (全部八页,逐位相同)
```

**所以碰撞只需要算一次。** 做出来的效果:
八页网格从 **3.64 秒变成 0.80 秒**,而且逐格的结果 **完全一样**(不是近似)。

### 第二件:唯一能区分八页的是**关节限位**

同一个姿态用不同写法,有的写法要求某个关节转到物理上转不到的地方。

翻一个符号,会把**两个关节各平移整整 180°**(中间那个取负,对合法性无影响)。
所以"翻完还合不合法"只取决于**限位离 180° 还差多少**:

| | q₁ | q₂ | q₃ | q₄ | q₅ | q₆ | q₇ |
|---|---|---|---|---|---|---|---|
| 真机限位(°) | 178.85 | 121.47 | 178.85 | 123.76 | 178.85 | 118.60 | 168.45 |
| **离 180° 的余量** | **1.15** | 58.53 | **1.15** | 56.24 | **1.15** | 61.40 | **11.55** |

这张表**完全预测**了实测结果:

| 翻哪个符号 | 动哪两个关节 | 余量 | 实测差异格 |
|---|---|---|---|
| `s₂` | q₁, q₃ | 1.15° | 60 格(1.6%),全在 θ≈0 一条细带上 |
| `s₄` | q₃, q₅ | 1.15° | 70 格(1.9%),同样一条细带 |
| `s₆` | q₅, **q₇** | **11.55°** | **340 格(9.1%)** |

余量 1.15° 意味着:只有原值落在 0 附近 1.15° 以内才会被推出界 ⇒ 差异是一条**细线**。
q₇ 的余量是 11.55°,是前者的十倍 ⇒ 差异是一**片**。
**这就是为什么八页图看起来几乎一样,而 `s₆` 那一对看起来明显不同。**

### 第三件:一面墙几乎能证掉八页

既然碰撞与页无关、限位只在细带上有差别,那么在一页上建好的墙,
搬到另外七页上应该照样有效。实测(EXP 2 在 `(++-)` 上建的 147 面墙,原封不动):

```
+++ 146/147      ++- 147/147 ← 它自己的页      +-+ 146/147      +-- 147/147
-++ 146/147      -+- 147/147                   --+ 146/147      --- 147/147
```

唯一失败的那一个面不是"切进了有效区",是一个 `pd=1.08e-5 < r=4.54e-5`
的擦边(数值问题,重训一次就能解决)。

**可以写进论文的命题:**

> 如果一面墙的**每个面**都因为"碰撞"或"IK 不存在"或"虚拟边界"而通过检查
> (也就是**完全不依赖关节限位**),那么这面墙在**全部八页**上都成立。
>
> 理由:碰撞和 IK 存在性都只是 `(y, θ)` 的函数,与符号分支无关。

这条是**可以自动检查的**:代码里 `check_facet` 本来就返回"为什么通过",
只要加一句"所有理由里都没有 joint-limit"就行。

实测这面墙的构成:62 面靠碰撞、23 面靠虚拟边界(**都与页无关**,占 58%),
62 面靠限位(依页)。所以还不能直接套用那条命题,但方向清楚了。

### 最后一句,也是最值得讲的一句

> **`Y⁺` 的"八页 + 门"这套结构,完全是关节限位造成的。**
>
> 如果限位是 ±180°,八页就**完全相同**,门也没有意义,
> 整个不可行性证明退化回单页问题。

这句话也顺手解释了为什么 EXP 4 只能靠 `s₆`:
八个余量里只有 q₇ 的 11.55° 大到足以真正改变连通性。

# 问题 6:"先每页各证一遍,再用 SVM 符号判断门在墙内外"

## 你的想法是什么

1. 八页各自先建好一面墙(不可行性证明)
2. 找出门的位置
3. 用 SVM 判别式的符号看门在墙的哪一侧:
   `sign(门) == sign(起点)` ⇒ 同侧 ⇒ 换页时不用重新证明

## 一个比方:多层楼和围栏

- **每一页 = 一层楼**
- **机器人 = 站在某个房间里的人**
- **终点 = 这一层的出口**
- **墙 = 我们围着那个房间搭的一圈围栏**,用来证明"他出不去"
- **门(奇异点)= 地板上的一个洞**,掉下去就到了另一层的同一个位置

## 对的那部分(而且代码里已经有了)

**用 SVM 符号判断洞在围栏内还是外,这是对的。**
墙是 `f = 0` 的零集,代码已经验证它是**一条闭曲线**,所以 `sign(f)` 就是内外。
而且门是一个**圆盘**不是一个点,整个圆盘必须在同一侧 ——
这一条 `check_facet` 的 Σ 守卫已经在强制了(**墙不许穿过任何圆盘**)。
两者合起来,查圆心的符号就**足够**判定整个圆盘在内还是在外。

## 不对的那部分:**方向反了**

```
sign(门) == sign(起点)   ⇒ 洞在围栏【里面】 ⇒ 人能走到洞口
                         ⇒ 【必须】去下一层再搭一圈围栏   ← 这是增加工作

sign(门) != sign(起点)   ⇒ 洞在围栏【外面】 ⇒ 人永远走不到洞口
                         ⇒ 这个洞可以直接【扔掉】        ← 这才是省工作
```

能省工作的是**后者**。而后者代码里也已经有了:`live_discs` 会把
"已经认证过关着的门"卸掉,这样建墙时就不用绕开一个根本过不去的洞。

## 更要紧的那部分:**"每页预先各证一遍"会把要证的命题换掉**

这是 §29 已经踩过的坑,有实测数字。

**证明的单位不是"层",是"(层, 房间)"。**

- 围栏必须围着**某一个具体的房间**搭。
- 但在你顺着洞走下去之前,**你不知道会落到 B 层的哪个房间**。
- 预先建墙就只能选一个播种范围。§29 选的是"所有挨着入口墙的房间",
  结果证的是一个**更强的命题**(每个这样的房间都围得住),
  而且**要求给人根本进不去的房间也搭围栏**。

实测代价:

```
播种范围 = 八页上所有碰到 y=0 的区域   →  γ 从 1.3 顶到 323–334,伙伴页的墙建不起来
播种范围 = 起点那一个位姿             →  两面墙分别 3.0 s 和 8.3 s,都建起来了
```

**所以"预先每页各证一遍"不是省工作,是把一个能证的命题换成一个更贵、
而且可能根本不成立的命题。**

还有一件事:**层是会被重复访问的。** EXP 3 的泛洪路径是

```
++- 的房间 1  →(过门)→  -+- 的房间 2  →(过门)→  ++- 的房间 1
```

同一层的不同房间要不同的围栏。按"层"记忆化会记错东西。

## 真正能省工作的三条

1. **按 `(层, 房间)` 记忆化。** `run_proof` 的队列已经在做了
   (访问过的房间不再入队)。
2. **用邻层的墙做热启动。** 把已建好的墙的训练集和 γ 当作新房间 Algorithm 1
   的初值。纯速度优化,零可靠性代价。
3. **按对称性复用证书。** 这就是问题 7 ——
   **一面墙在八页上 146–147/147 通过**,这才是真正能把"八面墙"变成"一面墙"的路。

## 两个问题的关系

| | 问题 6 的想法 | 实际可行的做法 |
|---|---|---|
| 复用的单位 | 页(层) | **(页, 区域)**,或**对称性**(Q7) |
| 符号判据的用途 | 判断"不用重证" | 判断"这道门可以扔掉"(方向相反) |
| 预先建墙 | 八页各一面 | 不行:会换掉命题,γ 1.3 → 334 |
| 真正的省法 | — | Q7:一面墙证八页(已实测) |

**一句话:你想省的那件事是对的,但省法在 Q7 里,不在 Q6 里。**
Q6 的符号判据本身没错,它只是用来**丢掉过不去的门**,而不是用来**跳过证明**。
