### EXP 2(ZGAP)— 判定正确,**证书未完成**,236.4 s

门 0 开 / 16 关;**起始分量到达终点 = False** ⇒ 不可行。然后:

```
alg1:  gamma=1.00  acc=1.0000  (133 start 类 / 449 goal 类)
alg4:  6 轮迭代,48 次 alg2,gamma=30.00(顶到上限)
       标号 87 拓扑 / 96 虚拟带 / 0 回退
WARNING  gamma 顶到上限:两类在 30 以下不可分,墙可能已碎
WALL:  111/122 面,closed=True  ->  incomplete
```

**失败的 11 个面全部聚集在页左边缘 y≈0**(图上橙圈),即墙贴着虚拟边界闭合的地方。
均匀采样落在 y<0.01 的只有约 1%,其中有效的更少,SVM 因此只有两三个点
告诉它起始区域的左边界在哪,于是切了进去。网格版没有这个问题,
因为网格在 y=0 上**正好有格子**。这是**局部**稀疏,不是全局稀疏。

| 阶段 | 秒 | 占比 |

| 1 采样 + classify | 3.25 | 1.4% |
| 2 路图连边(checkMotion) | 15.16 | 6.4% |

| 6 门纤维认证(16 道) | 0.66 | 0.3% |
| 7 **Alg 1 训练 SVM** | **0.06** | **0.0%** |
| 8 **Alg 4 外循环** | **153.91** | **65.1%** |
| 9 视频渲染 | 18.53 | 7.8% |
| 10 画图 | 2.33 | 1.0% |
| **合计** | **236.4** | |

**Alg 4 占 65%,而且是因为它失败才慢**:`find_inf_proof_region` 一旦
`rep.ok` 就立即返回,我们从不成功,于是 6 轮迭代、48 次 alg2 全部跑满。
网格版收敛后整个实验才 ~60 s。SVM 本身 **0.06 s**——换 C++/GPU 对此毫无帮助。
