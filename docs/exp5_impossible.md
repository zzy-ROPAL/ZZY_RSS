# EXP 5(q4 折叠线门)**结构性不可能** —— 实测与代数

结论:`docs/exp5_spec.md` 的条件 **B**(折叠点落在任务内部、两侧都可达)
和条件 **D**(起点与终点分居折叠线两侧、同一页内可跨过)**无法同时满足**,
**任何焊缝形状都不行** —— 弯焊缝也不行。

这不是"难搜",是**代数上不可能**。

---

## 1. 代数

`arm.py::ik_branch`:

```python
cos_q4 = (length**2 - d_se**2 - d_ew**2) / (2 * d_se * d_ew)
if cos_q4 > 1.0 or cos_q4 < -1.0:
    return IkResult(False, ...)          # 无 IK
q4 = s4 * arccos(clip(cos_q4, -1, 1))
```

于是

```
q4 = 0     ⟺  cos q4 = 1   ⟺  |x_sw| = d_se + d_ew = reach_max
IK 存在    ⟺  |cos q4| ≤ 1 ⟺  reach_min ≤ |x_sw| ≤ reach_max
```

**`q4 = 0` 的点集 = 可达圆环的外边界。** 折叠门永远长在可达集的**边界**上,
不可能长在内部。同理 `q4 = ±π` 对应 `|x_sw| = reach_min`,是内边界。

这把**不变量 22 推广了**:不变量 22 只说"直焊缝 ⇒ `|W−S|` 凸 ⇒ 折叠只在端点";
真正的原因与焊缝形状无关 —— **折叠点就是可达边界**,换什么曲线都躲不开。

---

## 2. 实测(真 `ik_branch`,圆弧焊缝,倾角 15°)

`reach_max = 0.651000`。圆弧:圆心 `(0.50, 0.34)`,张角 90°。

| 半径 | 峰值 `|W−S|` | 峰值 − reach_max | 不可达段 | 有没有折叠门 |
|---|---|---|---|---|
| 0.1360 | 0.647250 | −3.75e-03 | 0.00% | **没有** |
| 0.1390 | 0.650255 | −7.45e-04 | 0.00% | **没有** |
| **0.1400** | **0.651255** | **+2.55e-04** | **8.67%** | **有,但在不可达段两端** |
| 0.1410 | 0.652250 | +1.25e-03 | 19.17% | 同上 |
| 0.1440 | 0.655250 | +4.25e-03 | 35.07% | 同上 |

**没有中间地带。** R 从 0.1390 到 0.1400 只差 1 mm,就从"没有门"跳到
"8.67% 的焊缝够不着"。

逐点用真 IK 复核 R=0.140:

```
min |q4| = 0.004436 rad  @ y = 0.7720   |W-S| = 0.650998  (reach_max = 0.651000)
  左侧 y=0.7690 :  IK 不存在   |W-S| = 0.651033  >  reach_max
  右侧 y=0.7750 :  IK 存在     |W-S| = 0.650962  <= reach_max

全部 |q4| < 0.05 的点:  |W-S| ∈ [0.650807, 0.650998]
                        离 reach_max 最远 1.93e-04 m
```

小 `|q4|` 只出现在离可达边界 **0.2 mm** 以内。

## 3. 对 `exp5_spec.md` 各条件的影响

| 条件 | 判定 |
|---|---|
| A(焊缝非直线) | 成立,但**不够** —— 非凸只能把边界挪到 `y∈(0,1)` 内部,挪不走"它是边界"这件事 |
| **B**(折叠点内部、两侧可达) | **不可能**。两侧可达 ⇒ 峰值 < reach_max ⇒ `q4` 到不了 0 ⇒ 没有门 |
| **C**(门是开的,且认证精确) | 认证确实精确(整条 θ 线一个构型,已在 `7658380` 实现),但**"开"没有意义** —— 另一侧没有 IK |
| **D**(起点终点分居两侧、同页可跨) | **假**。"跨过去"不是换页,是走出工作空间 |
| **5b 的核心论证**(线门挡住墙 ⇒ 单页证明不存在) | **也失效**。若 `y > y*` 整段无 IK,页的有效集到 `y*` 为止,墙根本不需要跨过 `y*` —— 它可以从 `y*` 右侧的无 IK 区绕回去 |

`exp5_spec.md` §3 那组"`s4=±` 各 361 个 θ、余量 21.4°"的测量**本身没错** ——
它量的是**折叠点那一个构型**的限位余量。但余量再大也没用:
门的另一侧够不着,不存在"走过去"这件事。

(这和 §37 否决 `exp4_brief.md` 的理由**不同**:那次是只量端点没量路径(不变量 21);
这次是**另一侧根本不存在**。)

## 4. 还有没有线门可做

要的是一条**横跨整个 θ**、又**落在可达集内部**的 Σ 线。`q4` 折叠不行,
但 **`Σ_coord` 可能行**,理由是它**不是可达边界**:

```python
# ik_branch
u = x_sw / length
axis_align = abs(dot(u, e_z))
near_axis = axis_align > 1.0 - coord_axis_tol      # 臂角参考系失效
```

`x_sw = wrist(y) − shoulder` **只依赖 y**(工具姿态固定),所以
`axis_align` 也只依赖 y ⇒ **`Σ_coord` 同样是一条 θ-无关的线**。
而它退化的是**臂角的参考系**,不是可达性 —— 那里的构型**完全有效**。

需要的摆放:腕心几乎正对肩部正上方(`|u·ẑ| → 1`)。现有两个场景离得很远:

```
EXP 3  |u·z| 峰值 0.626      需要 > 0.999999
EXP 4  |u·z| 峰值 0.0997
```

**尚未搜索。** 两个要先回答的问题:

1. `Σ_coord` 是不是**真的门**?`assign_pages` 对空 `vanishing` 的处理是
   "保守地连接所有八页",但 `ik_branch` 在 `near_axis` 时只是把参考轴从
   `e_z` 换成 `[1,0,0]` —— 那是**换坐标**,不是换页。要先判清楚。
2. `find_coord_discs` 现在是**逐格**铺盘,不像 `find_fold_doors` 那样沿整条 θ 铺。
   要当线门用,得先改成线覆盖。
