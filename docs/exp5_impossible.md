## 原文(测量有效,结论无效)

结论:`docs/exp5_spec.md` 的条件 **B**(折叠点落在任务内部、两侧都可达)
和条件 **D**(起点与终点分居折叠线两侧、同一页内可跨过)**无法同时满足**,
**任何焊缝形状都不行** —— 弯焊缝也不行。

这不是"难搜",是**代数上不可能**。

## 1. 代数

`arm.py::ik_branch`:

```python
cos_q4 = (length**2 - d_se**2 - d_ew**2) / (2 * d_se * d_ew)
if cos_q4 > 1.0 or cos_q4 < -1.0:
    return IkResult(False, ...)          # 无 IK
q4 = s4 * arccos(clip(cos_q4, -1, 1))
```

于是

```
q4 = 0     ⟺  cos q4 = 1   ⟺  |x_sw| = d_se + d_ew = reach_max
IK 存在    ⟺  |cos q4| ≤ 1 ⟺  reach_min ≤ |x_sw| ≤ reach_max
```

**`q4 = 0` 的点集 = 可达圆环的外边界。** 折叠门永远长在可达集的**边界**上,
不可能长在内部。同理 `q4 = ±π` 对应 `|x_sw| = reach_min`,是内边界。

这把**不变量 22 推广了**:不变量 22 只说"直焊缝 ⇒ `|W−S|` 凸 ⇒ 折叠只在端点";
真正的原因与焊缝形状无关 —— **折叠点就是可达边界**,换什么曲线都躲不开。

## 4. 还有没有线门可做

要的是一条**横跨整个 θ**、又**落在可达集内部**的 Σ 线。`q4` 折叠不行,
但 **`Σ_coord` 可能行**,理由是它**不是可达边界**:

```python
# ik_branch
u = x_sw / length
axis_align = abs(dot(u, e_z))
near_axis = axis_align > 1.0 - coord_axis_tol      # 臂角参考系失效
```

`x_sw = wrist(y) − shoulder` **只依赖 y**(工具姿态固定),所以
`axis_align` 也只依赖 y ⇒ **`Σ_coord` 同样是一条 θ-无关的线**。
而它退化的是**臂角的参考系**,不是可达性 —— 那里的构型**完全有效**。

需要的摆放:腕心几乎正对肩部正上方(`|u·ẑ| → 1`)。现有两个场景离得很远:

```
EXP 3  |u·z| 峰值 0.626      需要 > 0.999999
EXP 4  |u·z| 峰值 0.0997
```

### 6.2 **过门这件事:两个代表元都在限位外,中间却是通的**

按不变量 21 独立查了一遍(查整条路径,不只查端点)。EXP 5b 的折叠点:

```
qA (页 ++-) = [0, 78.359,   0, 0, 180, -71.641, 0]   q5 = 180.000  > 178.85  超限
qB (页 +--) = [0, 78.359, 180, 0,   0, -71.641, 0]   q3 = 180.000  > 178.85  超限
qB - qA     = (q3 +180, q5 -180)   <=  正是 q3/q5 零运动的 delta = +-pi 点
```

沿零运动扫 δ(相对参考拼法):

```
可行区间 = [-178.855, -1.145] U [+1.145, +178.855]  (度)
  delta = 0     被 q5 挡住   (差 1.145 度)
  delta = +-180 被 q3 挡住   (差 1.145 度)
```

**正是 §30 那个 q2 门的同一个 1.145° 缺口。**

但这**不等于门关着**。换个 θ 再看:

```
y* - 1e-4,  theta = 0.00 :  ++- q5 = -179.998 超限   +-- q3 = -180.000 超限
y* - 1e-4,  theta = 2.00 :  ++- (q3,q5) = (114.592,  65.409)  在限位内,无碰撞
                            +-- (q3,q5) = ( -65.408,-114.591) 在限位内,无碰撞
```

**θ=2.0 处两页的拼法都在限位内、都无碰撞** —— 门两侧机器人都待得住。
但这两点之间**差的仍是 (q3 −180, q5 −180)**,也就是零运动的 δ=∓π,
而从 θ=2.0 的拼法出发,零运动的可行 δ 区间够不到 ±180。
直线关节插值 201 步里 40 步越限,也不是合法路径。

**结论**:两个页拼法**各自可达**,但**折叠点上的零运动连不通它们**。
机器人能不能用别的方式换页(先离开折叠点、绕一圈再回来),是 `Q` 里的
**路径规划**问题,不是坐标卡的问题,本会话没有判定。

### 6.3 这对两个判定各意味着什么

| | 受影响吗 | 为什么 |
|---|---|---|
| **EXP 5b `proven=True`** | **不受影响** | 不变量 2:把门当开只会**多做功**。即使门其实过不去,两页两面墙的证书照样成立 —— 它证的是更强的命题 |
| **EXP 5a′ 的墙 301/301** | **不受影响** | 那是起始页自己的闭合证书,和门无关 |
| **EXP 5a′ "task feasible via `+--/1`"** | **要小心措辞** | `proven=False` 的含义是"**证不出不可行**",不是"**证明了可行**"。可行性要**见证路径**,墙给不出。如果汇报里说"机器人换页之后把焊缝走完了",需要先解决 6.2 |

`certify_fold_door` 的判据是 `ok = bool(admissible)`(可行集非空)。
对 5b/5a′ 这两个场景它给出的"开"是**对的**(两页拼法确实各自可达),
但"非空"在一般情况下**不足以**保证两页拼法之间连通 ——
若可行集窄到只有几度,零运动就转不过那 π。建议把判据加强为:
**可行集中是否存在一个连通区间同时容纳两页的拼法**。
