## 0. 一句话

1-D 焊缝任务。机器人**起始位姿所在的页到不了终点**——这一点由 IJRR
Algorithm 1–4 学出的**一道闭合墙**证明;它随后经一个 **q6 门**换到伙伴页,
在那一页**把焊缝走完**。所以 `run_proof` 给出
`proven=False, goal_reached_via="+--/1"`,而**墙正是让这个答案有意思的东西**:
任务只有**跨两张图**才可行。

**这是本项目第一道机器真能执行的换页。**

## 1. 为什么不用 `docs/exp4_brief.md` 的场景

那个场景(焊缝 x=0.40 z=0.22 倾角 45°,盒子 (0.095,0.29,0.377),
页 `-++ → -+-`,门 y=0.7261)**四条判据全部复现**,res 61/81/101 都成立。
**但门过不去**,而且交接说明里的"余量 +14.46°"**量错了对象**。

q6 门是**腕部万向节**:`q6=0` 让 q5/q7 两轴共线,`(q5+δ, q7−δ)` 不动机械臂。
伙伴页对同一个臂形的代表元在 **δ=±π**。所以过门 = **走完整条纤维**,
中间每一步都要在限位内:

```
δ: 0 → +π   需要   q5_0 ≤ L5 − 180°   且   q7_0 ≥ −L7 + 180°
δ: 0 → −π   需要   q5_0 ≥ −L5 + 180°  且   q7_0 ≤  L7 − 180°
```

L5=178.85°、L7=168.45° ⇒ 两个窗口只有 **1.15°** 和 **11.55°** 宽。
那道门 `q5_0=−59.84°, q7_0=−136.62°`,有效区间 **δ∈[−119.0°, +31.7°]**:
含 δ=0,**两端都不含**。交接说明只查了**终点**,用的是 `mirror_q`,
而它把 q7 从 **−316.62° 回绕成 +43.38°** —— 回绕后的值在限位内,
**但关节转不过去**(要先经过 −168.45°)。
和 §30 的 q2 门同类,只是晚一步暴露。详见 findings §37。

**不变量 21 据此更正**:q6 门**不是**天然可穿越,要逐例查上面那两个窗口。
好消息是窗口不空:5544 个摆放、1660 道内部 q6 门里,**2233 个页/门对可穿越**。

## 2. 场景

```python
# scripts/run_exp4.py 的 EXP4
焊缝  p0=(0.44, −0.34, 0.22)  p1=(0.44, 0.34, 0.22)  倾角 45°   (直线)
障碍  'cut'   center=(0.18,  0.30, 0.34)  half=(0.07,0.07,0.07)   14 cm 立方
      'split' center=(0.18, −0.06, 0.42)  half=(0.05,0.05,0.05)   10 cm 立方
起始页 +-+ / 区域 1        伙伴页 +-- / 区域 1
门     y=0.6674  θ=−0.2571  (q6 门),过门方向 δ: 0 → −180°
```

### 两个盒子,两件事(§24 的 ZGAP 分工,这次用在**墙**上)

| 盒子 | 职责 |
|---|---|
| **cut** | **造出实验**:让 `+-+` 的起始区域到不了终点,而 `+--` 的门所在区域仍跨到 y=1 |
| **split** | **让实验可证**。没有它,`+-+` 上起始区域与终点分量之间**只隔着 θ≈0 的关节限位发丝**(q3 超限 1.15°)。实测这条发丝**连续宽度只有 1.2–1.7°**,不到一格的三分之一,缩放单位下 0.0065–0.0094,**还不到回灌守卫 0.019 的一半** —— SVM 零集放不进去,约 6 个面永远判不过。`split` 坐在 θ≈0 的肘部轨迹上,把发丝变成**碰撞带**。碰撞与页无关,所以它同时从 `+--` 上拿掉这些格子,而这**不损失任何东西**:`+--` 的贯通路线走 θ<0,经 θ=−0.257 的门 |

实测对照(res 61):

| | 瓶颈(缩放单位) | 墙 |
|---|---|---|
| 只有 `cut` | 0.033(= 1 个 θ 格,就是发丝) | 最好 186/192,随后 Alg 4 越走越偏:175/193 → 155/202 → …,γ 顶到 400 |
| `cut` + `split` | **0.090** | **169/169,闭合,γ=2.7,Algorithm 4 只跑了 1 轮** |

"瓶颈"的定义(`scripts/search_exp4_scene.py`):墙是**无效集中**把起始区域 R1
与终点分量 G 分开的闭曲线;任何这样的曲线 C 与任何 R1→G 的路径 P 必相交,
于是 `min_C 深度 ≤ max_P 深度`,且可取等。所以最好的墙能有的余量是

```
瓶颈 = min over R1→G 路径 ( max 路径上的 C_obs 深度 )
```

一个 minimax 路径值,用**缩放页坐标**(y∈[0,1]、θ/π∈[−1,1])度量,与分辨率无关。
**必须在 res ≥ 61 上筛**:res 41 的一个 θ 格已经是 0.05 缩放单位,
发丝和真带读数相同,筛子形同虚设。

### 机器人到底被什么挡住(汇报时最常被问的一条)

**不是**"看上去没撞到"。沿焊缝直走,**前臂撞上 `cut` 盒**:

| y | 碰撞 | 间隙 | 穿透 | 见证 |
|---|---|---|---|---|
| 0.800 | 否 | 13.34 mm | — | forearm/cut |
| **0.8167**(卡住处) | 否 | **5.72 mm** | — | forearm/cut |
| 0.833 | **是** | −1.61 mm | **1.61 mm** | forearm/cut |
| 0.867 | 是 | −16.48 mm | 16.48 mm | forearm/cut |

起始区域 207 个边界格里 **137 个是碰撞**、70 个是限位;**+y 方向 20 碰撞 / 9 限位**。

**那绕过去呢?** 绕路在 θ≈−2.4 那条低臂角走廊。它在 `(+-+)` 上是**限位**无效:

| y | θ | `(+-+)` | `(+--)` |
|---|---|---|---|
| 0.900 | −2.409 | **q7 = −179.4° 超出 ±168.45°** | VALID |
| 0.933 | −2.409 | **q7 = −176.0°** 超限 | VALID |
| 0.967 | −2.513 | **q7 = −170.3°** 超限 | VALID |

**完整因果链**:碰撞封死直路 → 限位封死绕路 → 过 q6 门,`s₆` 镜像把 q7 平移
180° 拉回限位内 → 在 `(+--)` 上走同一条走廊,**以 2.61 mm 的间隙从同一个盒子旁边挤过去**。

这也说明为什么**两个盒子缺一不可**,以及为什么这个实验必须讲"页",
而不能只讲"有障碍所以走不通":**挡住机器人的是碰撞,挡住绕路的是限位,
而限位是逐页不同的** —— 碰撞与页无关(§31),限位不是。

### 墙的**包含性**检验(本次新增)

Algorithm 1 报 accuracy=1.0 只说明**训练点**都在正确一侧,而训练集是
(ε,η)-net **子采样**;闭合性与"每个面在 `C_obs` 内"说的是**曲线在哪**,
不是**它围住了什么**。所以对**每一个有效格**做一次奇偶环绕判定:

```
505/505 起始区域格在墙内        680/680 终点分量格在墙外
```

证书的完整主张因此是:**闭合 ∧ 每面在 C_obs 内 ∧ 起点在内 ∧ 终点在外**。

## 4. 分辨率与种子稳健性

场景结构在 res 41/61/71/81/91/101/121 上**都成立**(起始区域 y_max
0.817/0.825/0.840 随分辨率单调,伙伴页跨越,门可穿越,θ 接缝干净),
**瓶颈也几乎不变**(0.0898 / 0.0901 / 0.0922 @ 61/81/101)。

**但墙闭不闭合,还取决于 (ε,η)-net 的那一次抽样。**
实测 6 分辨率 × 6 种子 = 36 次抽样,**26 次给出完整证明**:

| res | 完整证明 | 备注 |
|---|---|---|
| 61 | **5/6** | 默认种子 20261029 可以 |
| 71 | 4/6 | |
| 81 | 3/6 | **默认种子失败**(306/309, γ=30.2);种子 2/3/5 可以 |
| 91 | 5/6 | |
| 101 | **6/6** | 默认种子可以 |
| 121 | 3/6 | 默认种子可以 |

逐行表见 `out/exp4_seeds.md`。失败的那几次 γ 跑到 200–320、面数炸成
863/869 这样,**而几何瓶颈完全一样**(0.0898 / 0.0901 / 0.0922 @ 61/81/101)。

**还抓到一例"看着像成功"的失败**:res 81 / seed 1,`167/168` 面、
`closed=True`、`γ=1.5`,只差一个面,但**一个起始区域的格子落在墙外**——
`containment_check` 拦下了它(不变量 27、§39)。

**这不影响可靠性**:Algorithm 3 只会"**证不出来**",不会"证出假的"。
抽到坏样本的结果是 **INCONCLUSIVE**,不是反证,所以重抽是正当的
(`run_exp4.py --seed`)。但它应当被如实记下:
**墙能否闭合不是场景的函数,是 (场景, 抽样) 的函数。**

默认种子 20261029 在 res 61 / 101 / 121 上都给出完整证明;
**res 81 在默认种子上失败**(306/309,γ=30.2),换种子 2、3 或 5 即可
(173/173 γ=2.3;163/163 γ=2.2;169/169 γ=2.8)。

**汇报时不要说"这个场景的墙是 169 个面"**,要说
"这次抽样给出 169/169,36 次抽样里 26 次给出完整证明"。

| 阶段 | s |
|---|---|
| 八页图 + 16 道门 | 1.4 |
| 墙(Algorithm 1–4,1 轮) | 1.3 |

| **合计** | **54.9** |

**判定本身 2.4 s;GIF 占 89%**,与 §17/Q1 的结论一致:瓶颈在渲染。
对照:交接说明记录的 `run_proof` 是"13 分钟未出结果"。
那有两个原因,都已修掉:

1. `train_wall` 线性爬 γ 梯子(0.1 一档,gamma_max=400 ⇒ 最多 3990 次 SVM
   拟合)。实测**单次调用 70.6 s @ γ=227**,而 Alg 2/Alg 4 每区域还要重训多次。
   改为**指数括号 + 二分**(同一把梯子,且**重拟合下一档并要求它失败**),
   约 **25 次**拟合。开关 `WallParams.gamma_search`,`"linear"` 保留 IJRR 原文。
   **EXP 2 与 EXP 3 逐位复现**(145/145;159/159 + 161/161;`run_proof`
   162/162 + 163/163,1.5 s)。
2. 真正的阻碍是几何,由 `split` 盒子解决(§2)。

## 7. 仍然成立的保留

1. **碰撞几何还是胶囊近似**(STL 网格未获得)。一切由碰撞驱动的结论——
   包括 `cut` 和 `split` 的作用——都是**暂定的**。换成真网格必须重跑。
2. **门的认证仍是采样**(纤维是 `Q` 中零测集,待办 5)。但这里比 EXP 3 强:
   过门路径是**一条一维曲线上的 181 个点**,且两端点都是解析已知的代表元,
   不是在二维纤维上撞运气。要严格仍需区间算术。
3. **墙的闭合依赖抽样**(§4)。
