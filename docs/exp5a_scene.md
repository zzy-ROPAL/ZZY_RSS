## 1. 场景(完整规格,可直接复现)

```
焊缝   圆弧,中心 (0.15, -0.10, 0.45),半径 R = 0.449530
       弧平面法向 = z,arc_ref = x
       焊枪 approach 由 tilt = 170°、azimuth = 90° 给出
       弧跨度:以远点 phi_far 为中心,[-1.4, +1.7]
       => 折叠门 y* = 0.451613

障碍   一个 12 cm 立方体
       center = (0.2988, -0.0121, 0.3747)   half_extent = (0.06, 0.06, 0.06)

起始页 A = (++-)        伙伴页 B = (+--)     (差 s4,正是折叠门连接的那一对)
```

半径 **不是搜出来的,是解出来的**:给定中心与工具轴,切点条件
`hypot(dn, rho + R) = reach_max` 对 R 是**闭式**的,所以每个摆放都自带
一个精确的内部折叠门(残差实测 −7.98e-09,受 2001 点采样精度限制,
构造上是精确的)。

## 3. 为什么 `s₄` 这次能用上(§37p 想错的地方)

§37p 的机制说:带厚 ≈ `r_elbow × 0.02/|dq3/dθ|`,所以要把 `|dq3/dθ|`
压到 0.096 以下。**实测这个预测是错的** —— 本场景的 `min|dq3/dθ| = 0.76`,
比之前**更大**。带之所以够厚(`band_thickness` 最大 68.44 mm > 60 mm 胶囊,
2 格可分离),靠的是**大圆弧半径 R = 0.45** 与 **cy ≠ 0 打破对称**,
跟那条机制无关。

教训和前三次一样:**机制可以指方向,不能当判据;扫描的参数范围才是判据,
而我把中心位置挡在了范围之外。**
